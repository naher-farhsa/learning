Claude Workflow Lifecyle

+--------------------------------------+
| Explore --> Plan --> Code --> Commit |
+--------------------------------------+

Explore gives Claude the relevant context it needs for your project.
Plan creates a plan of action that Claude uses to measure success.
Code is the back and forth between you and Claude before settling on the final outcome.
Commit helps you review and push your code so you can start on your next feature.

========================================================================================================================



Start Claude:
------------------------------------------------------------------------------------------------------------------------
- /init   : Generates a starter CLAUDE.md 
- /effort : Calibrates processing cycles by choosing Claude (Low/Medium/High/Max) evaluates the codebase prior to editing.
- /model  : Opens a dynamic prompt to swap the current base model mid-session.

Scope & Steer Claude:
------------------------------------------------------------------------------------------------------------------------
- /plan        : Switches Claude into an explicit planning state prior to executing major architectural changes.
- /goal        : Sets a fixed termination condition (e.g., "until all tests pass") and lets Claude run iteratively.
- /loop        : Executes a specific diagnostic prompt or test command on a continuous repeat sequence.
- /background  : Detaches the current CLI terminal session so Claude can complete a task as a background agent
- /schedule    : Configures a prompt to execute on an automated background timer.

- /memory      : Opens a menu to edit persistent rules. Update User memory (global via ~/.claude/CLAUDE.md) or Project memory (committed via ./CLAUDE.md).
- /compact     : Compresses your active token and message history into a clean summary
- /clear       : Wipes the current chat history to begin fresh on an entirely separate ticket. (Aliases: /reset, /new).
- /fork [name] : Splits the current session history into an isolated branch to safely test parallel development tracks.
- /rewind      : Serves as a full roll-back function for terminal commands and AI history. (Alias: /checkpoint).
- /btw         : Injects a side question or piece of context without interrupting Claude's active execution thread.

- /context     : Generates a color-coded usage grid mapping remaining limits.
- /usage       : Displays an explicit running count of cumulative tokens and API costs.
- /cost        : Returns instantaneous telemetry showing cumulative session token counts and active dollar usage.
- /code-review : Evaluates active file modifications or specific PR IDs for edge cases, bugs, and style flaws



Configure Claude: 
------------------------------------------------------------------------------------------------------------------------
- CLAUDE.md        : Permanent personalized conventions/guide tech stack, dos & donts, coding style, and build commands without requiring you to re-explain them. (Workspace/User)

- Subagents        : Main Agent split and delegate tasks to each subagent that will operates in its own isolated context window running in parallel, improving context management.

- SKILL.md         : SOPs on how to perform a specific, multi-step task or workflow on demand.

- Hooks            : Run custom shell scripts, HTTP requests, or code automatically at specific moments in the ClaudeCode lifecycle, configured via (settings.json (global/workspace/user)

- Permission Modes : Control how an AI tool handles file edits and commands

  - manual           : The tool asks you before every single action or change.
  - dontAsk          : The tool runs tasks without asking you for permission.
  - plan             : The tool creates a step-by-step guide before it makes changes.
  - acceptEdit       : The tool applies text and file edits automatically.
  - auto             : The tool makes decisions and runs standard actions on its own.
  - bypassPermission : The tool skips all safety checks and security blocks.
