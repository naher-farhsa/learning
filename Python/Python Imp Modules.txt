Top 10 Built-In Modules (Most Used in Python):

-----------------------------------------------------------------------------------------------------------------------------------------------------------

| Module        | Primary Use              | Most Important Methods / Classes                           | Keywords / Trivia                               |

| ------------- | ------------------------ | ---------------------------------------------------------- | ----------------------------------------------- |
 
| `typing`      | Type hints               |`Optional` `TypedDict`, `Annotated`, `Field, `Literal`      | Static Typing, Type Checking and Validation     |

| `asyncio`     | Async programming        | `run()`, `create_task()`, `gather()`, `sleep()`            | Event Loop, Coroutines, `async/await`           |

| `os`          | OS & filesystem          | `listdir()`, `walk()`, `mkdir()`, `remove()`, `environ`    | Environment Variables, File Operations          |

| `pathlib`     | Modern path handling     | `Path()`, `exists()`, `glob()`, `mkdir()`, `read_text()`   | Object-Oriented Paths, Preferred over `os.path` |

| `json`        | JSON serialization       | `load()`, `loads()`, `dump()`, `dumps()`                   | REST APIs, Config Files                         |

| `collections` | Advanced data structures | `Counter`, `defaultdict`, `deque`                          | Counting, Queue, Frequency Maps                 |

| `itertools`   | Efficient iteration      | `product()`, `chain()`, `combinations()`, `permutations()` | Lazy Evaluation, Memory Efficient               |

| `functools`   | Functional programming   | `lru_cache()`, `reduce()`, `partial()`, `wraps()`          | Memoization, Decorators, Caching                |

| `re`          | Regex                    | `search()`, `match()`, `findall()`, `sub()`                | Pattern Matching, Validation                    |

| `datetime`    | Date & time              | `datetime.now()`, `timedelta`, `strftime()`, `strptime()`  | Scheduling, Time Calculations                   |
